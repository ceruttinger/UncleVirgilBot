Build summary

Important source warning

The current corpus_data.json appears to have been created after the old setup script removed numbers from the text. That means many years and exact dates are missing. The public text and search work, but the timeline should be treated as provisional until the corpus is rebuilt from the raw chapter .rds files or scanned PDFs.

Use this order:

mkdir -p data/raw_scans
# copy CH-01.rds ... CH-11.rds into data/raw_scans/
Rscript R/00_rebuild_raw_text_from_rds.R
Rscript R/render_all.R
quarto preview

If you only have scanned PDFs:

mkdir -p assets/pdf
# copy CH-01.pdf ... CH-11.pdf into assets/pdf/
Rscript R/00_ocr_scanned_pdfs.R
Rscript R/00_rebuild_raw_text_from_rds.R
Rscript R/render_all.R
quarto preview
