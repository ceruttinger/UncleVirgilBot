Named Entities

Named entities are the people, places, organizations, dates, and other proper references that structure the memoir.

For this project, entity extraction is intentionally treated as a candidate-and-review workflow. OCR is noisy, family names are domain-specific, and the source text may be lower-case in places, so a generic named-entity model would miss important names and hallucinate others.

How to read this page

  • Entity registry: one row per candidate entity across the memoir.
  • Entity mentions: chapter-level mentions of each entity.
  • Dates: four-digit year candidates. These need review because some years are chapter-period dates while others are historical background or later reflection.
  • Review status: starts as candidate. Later we will promote trusted entities to accepted and remove false positives.

title: "Named Entities"

Named entities are the people, places, organizations, dates, and other proper references that structure the memoir.

For this project, entity extraction is intentionally treated as a **candidate-and-review workflow**. OCR is noisy, family names are domain-specific, and the source text may be lower-case in places, so a generic named-entity model would miss important names and hallucinate others.

## How to read this page

- **Entity registry**: one row per candidate entity across the memoir.
- **Entity mentions**: chapter-level mentions of each entity.
- **Dates**: four-digit year candidates. These need review because some years are chapter-period dates while others are historical background or later reflection.
- **Review status**: starts as `candidate`. Later we will promote trusted entities to `accepted` and remove false positives.

## What comes next

The next improvement is to manually edit `data/entity_seeds.csv` and add names, places, institutions, and events that the automatic pass missed. After that, we can promote reviewed rows into a durable entity registry for the graph database and chatbot retrieval layer.
